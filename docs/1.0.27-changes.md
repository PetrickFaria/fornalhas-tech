# Fornalhas Tech 1.0.27

Starting point: `main` at `e635140c263f9ddb576b98c4a8f5e498ffd29e21` (1.0.26).

## Changes

- Expanded each of the 24 recessed animated corner details from a 10% to a 25% side length, relative to the unchanged 1.96875-unit corner cube. The channel width is 0.4921875 model units (0.03076171875 block units). The metal rims, cavity walls, inset caps, color tint, animation sheet, and recessed depth remain in place.
- Verified and retained the eight existing cube centers at the eight body vertices: every center is an exact combination of 0 or 16 model units. Cube dimensions and the 1.96875-unit envelope are unchanged; no edge bars are reintroduced.
- Removed the one-tick `LIT` gap at a fuel boundary. After recipe work and any smelt completion, the server checks whether another valid recipe can still fit in the output. It primes the next fuel only at zero remaining burn and only when that work exists; the final block state is then applied once. No artificial light delay or extra burn-work step is added.
- Updated environmental block light to 0/10 without a core (idle/burning) and 10/15 with a core (idle/burning).
- Applied a one-pixel optical offset to the main-screen `P`, without changing its 14x14 bounds. Enlarged the customization-screen return frame by a one-pixel surround, kept the existing `P` pixels unchanged, and expanded hover/click/tooltip bounds to 16x14.
- Advanced the shared Gradle/mod metadata version to 1.0.27.

## Verification

`tools/validate_visual_refinements_1_0_27.py` checks all three base-model variants, cube centers and dimensions, 24 exact square channels, matching dynamic quads, fuel transition ordering, light-level mapping, button bounds, and version. Java tests check fuel cadence/units, the no-work handoff rule, and all four light states.

This is source/geometry and CI validation. The Minecraft client was not launched here, so actual in-game camera appearance, chunk-light updates, and control feel remain unverified.
