# Fornalhas Tech 1.0.28 — inward diagonal corner-cube shift

Base: `main`, commit `703bf0adcd835de70cc62271b9779de6c6bf25c1` (1.0.27).

Only the eight corner-cube assemblies on the Base furnace model and their matching recessed emissive squares were repositioned. The assemblies were translated rigidly; their dimensions, faces, UVs, material assignments, normals, and rotations were not changed.

## Applied translation

Model coordinates use 16 units per block. Each axis component is exactly 0.375 model units (3/128 block per axis):

- Corner at coordinate 0 on an axis: `+0.375` on that axis.
- Corner at coordinate 16 on an axis: `-0.375` on that axis.
- Spatial displacement length: `sqrt(3) × 0.375 = 0.6495190528` model units.
- Renderer-space translation per axis: `0.375 / 16 = 0.0234375` block units.

|---:|---|---|
| 0 | (0, 0, 0) | (0.375, 0.375, 0.375) |
| 1 | (0, 0, 16) | (0.375, 0.375, 15.625) |
| 2 | (0, 16, 0) | (0.375, 15.625, 0.375) |
| 3 | (0, 16, 16) | (0.375, 15.625, 15.625) |
| 4 | (16, 0, 0) | (15.625, 0.375, 0.375) |
| 5 | (16, 0, 16) | (15.625, 0.375, 15.625) |
| 6 | (16, 16, 0) | (15.625, 15.625, 0.375) |
| 7 | (16, 16, 16) | (15.625, 15.625, 15.625) |

Every cube remains `1.96875 × 1.96875 × 1.96875` model units. All model components named `vertex126_{id}_...` were translated by the same vector for that corner, including rims, channel walls, and static caps. The 24 animated recessed quads moved by the matching normalized vector. The squares remain `0.03076171875` block units wide (25% of the cube side).

No edge bars were added. Main faces, textures, GUI, fuel, recipes, core/color behavior, lighting logic, and other furnace modes were not changed. The existing build workflow runs the Java 17 build and the updated deterministic geometry/invariant checks.
