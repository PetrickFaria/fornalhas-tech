# Fornalhas Tech 1.0.32

This update applies the requested focused visual refinements:

- Refines all five 64x32 fire sheets: zero-alpha texels carry edge colors instead of black RGB, the visible flame tips gain one pixel of height, and the fixed base remains unchanged. The panel quad is slightly wider and taller while remaining within the lower opening.
- Draws fire on one canonical North-facing quad and rotates it around the block center using the block's `FACING`, so the same UV orientation and winding are used in all horizontal directions.
- Emits occasional vanilla flame particles just outside the true front face while the block's fuel-lit state is active. Existing color particles remain tied to actual cooking.
- Darkens medium/dark gray pixels in the six face textures and the shared dark steel material; black outlines, bright silver, emissive masks, and accent colors are preserved. Vertex-cube neutral metal uses a matching graphite tint.
- Raises the main GUI `P` glyph by one pixel. Replaces the customization screen's old bitmap return glyph with the same framed `P`, drawn at 11x11 (75% of the main 14x14 size rounded to whole pixels) with a 0.75 glyph scale and a matching hitbox.
- Flattens only the lower-face down-texture and channel-wall extrusion from 0.625 units to 0.01 units; the bottom-face footprint, UVs and texture remain unchanged. Other model geometry is preserved.

Validation is provided by `tools/validate_visual_refinements_1_0_32.py` and the existing Java unit checks in the GitHub Actions workflow. In-game visual inspection is still required to confirm appearance under Minecraft's renderer.
