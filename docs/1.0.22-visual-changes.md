# Fornalhas Tech 1.0.22

Base: branch `main`, commit `373685fd37d7fc16c135ec36ebb5f43f8d38d1e0` (1.0.21).
Minecraft 1.19.2 / Forge 43.5.0 / Java 17; no Java or gameplay changes.

## Supplied textures

Source archive: `Fornalha_Tech_Base_6_faces_64x64(4).rar`.
It contains TWO sets: the root files retain the old #636363 light gray and #343434 front openings;
the nested `Fornalha_Tech_Base_6_faces_64x64/` contains the revised #9B9B9B gray and #090909 openings.
This release uses the revised nested set. Mapping is literal north/front, south/back, west/left,
east/right, up/top, down/bottom, with no flips, rotation, smoothing or resizing.
Only #9B9B9B is brightened to #BBBBBB. All other non-red pixels are unchanged.
Red #ED1C24 defines the emissive mask; these pixels are white in the tintable layer.
The non-emissive texture stores neutral metal at these same pixels for the no-core model.
The bottom texture is pixel-identical to 1.0.21 and has no emissive pixels.
The existing client color handler and blockstate rotations are unchanged.

## Geometry closure

The previous body used independently inset faces with different tangent/normal bounds.
Emissive faces occupied 15.75 units against 16-unit structural UVs, so masks were misaligned.
The surface is now a complete six-sided height field with a wall at every depth transition,
plus an opaque closed inner body. Each UV cell belongs to exactly one surface; emissive regions
are actual inset surfaces rather than overlapping face-wide translucent overlays.
All face elements have finite inward thickness and no cullface directive. Sidewalls are opaque.
The original 12 edge bars and 8 corner cubes are retained exactly. Existing raised surface masks
and heights (.125 units, .625 on the bottom) and front cavities (.372 depth) are preserved.
Colored channels remain at .372 depth. Their UV span now matches the outer faces exactly.
Closed wall thickness is .001 toward the interior; no raised dimensions were increased.
The inner body is hidden behind these exterior surfaces and seals the volume.
Both colored and neutral models receive the same geometry. Blast furnace/smoker models unchanged.

## Core sprites

Six 64x64 transparent item PNGs replace the six existing core sprites. Existing item/generated
models remain unchanged, so the same resource is used in the inventory, hand and dropped item.
Concept: rounded segmented silver capsule, dark outlines, luminous cross and central jewel.
Generated from the supplied Base reference using the built-in image tool, then five color variants
preserving the template. Technical downsampling to 64x64 uses nearest neighbor only.
Prompts: isolated front-facing Minecraft pixel-art technological core, silver armor quadrants,
charcoal separations, central jewel and cross circuits, transparent background, no text/recipe.
Variant prompts change only the colored circuitry/jewel to white, gold, green, cyan or dark copper.
The block's approved runtime tint palette is not edited.
