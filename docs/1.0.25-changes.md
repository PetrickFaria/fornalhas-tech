# Fornalhas Tech 1.0.25

Base: main, b1bcb94c5c1bd7bd960f8eaddf8739e78cea3059 (1.0.24).

## Active burn and light

The registered light predicate was using COOKING, which is false with empty input or blocked output even when burn ticks remained. It now reads LIT; the server furnace tick sets LIT directly from burn > 0, independently of recipe/input/output. The same LIT state drives the already existing energy animation speed. Core presence still selects the approved pairs: idle 0/10, burning 5/15. Burn speed/duration, cooking, output, items and NBT were not edited. Core insertion/removal updates the CORE blockstate; the next furnace tick tracks persisted burn state after world/chunk load.

## P glyphs

Main-screen P coordinates now derive from the 14x14 button size and font metrics, snapped to integer GUI pixels; its font and size, button art and click box remain unchanged. Customization's small top-right control had a tiny pixel-art return symbol, not a text P. Its 14x14 bounds, outer border, texture, click area, and return behavior remain; only its inner mark was replaced with a larger, crisp 7x7 dark pixel P.

Java 17 test executes the exact light-level function wired into the Block properties for all four core/burning combinations. CI retains the 1.0.24 build, animation clock and fuel-work tests. A software pixel preview shows the button texture edit; no Minecraft session was available, so screen-scale positioning, real block-light propagation, animation switching with burn, and gameplay clicks remain to be checked in game.
