# Fornalhas Tech 1.0.33

Focused visual update based on 1.0.32.

- Fire sparks are emitted at 2.5 times the previous random-tick chance (150% more frequent), are scaled to 25% of vanilla flame size, and originate along the lower front fire opening with a small outward offset for each facing.
- The five-frame fire overlay is built directly on the north, south, east, or west front plane with outward winding and matching normals. Its sheet is offset toward the viewer from the recessed black insert to avoid coplanar depth flicker, but stays behind the front metal bezel. This removes the prior second rotation transform that could disagree with the blockstate model rotation.
- The existing metallic grays on the five exterior face textures and dark steel material receive a restrained pixel-stepped brushed-metal refinement. The already-dark underside, black outlines, saturated details, emissive masks, model geometry, and the five fire animation frames are unchanged.
- Version metadata now derives from `mod_version` in `gradle.properties`.

The GitHub Actions build validates resource dimensions and source invariants. In-game visual verification still requires launching Minecraft with the mod.
